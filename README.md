## Projects

###  [TTC Transit Delay Analysis](./ttc-transit-delay-analysis)
Identified the operational and environmental factors most predictive of TTC service delays using Random Forest feature importance, and built an ARIMA time-series model to forecast weekly delay volume.
**Tools:** Python (pandas, scikit-learn, statsmodels)

###  Toronto Neighbourhood Data Integration Pipeline
Built an ETL pipeline using DuckDB to consolidate and clean multiple City of Toronto socioeconomic datasets into a unified, analysis-ready table — benchmarked against a pandas-based approach.
**Tools:** Python, DuckDB, SQL

### Cell Tower Coverage Analysis
Analyzed cell tower distribution data to identify regional coverage gaps and density patterns, with a Tableau geospatial map and Power BI executive dashboard highlighting underserved areas.
**Tools:** Python, Tableau, Power BI
